# Panduan Login JXFleet

Panduan ini menjelaskan alur masuk (*login*) ke platform **JXFleet** untuk seluruh pengguna (Admin, Tim Ops, dan Driver) di berbagai perangkat.

---

> [!IMPORTANT]
> Pastikan nomor handphone yang Anda gunakan telah didaftarkan terlebih dahulu oleh **Tim Pengembang JXFleet (JXFleet Developer Team)**. Jika pertama kali login, PIN awal secara default adalah `123456`.

---

=== "💻 Komputer (Desktop Web)"

    ### Langkah-Langkah Login via Desktop Web:

    1. Buka peramban (*browser*) di komputer Anda dan akses halaman [web.jxfleet.com](https://web.jxfleet.com).

    ![Halaman Utama Web JXFleet](){ width="60%" .center }

    2. Masukkan nomor handphone yang telah terdaftar pada Tim Pengembang JXFleet (diawali kode negara `62`), lalu klik tombol **Selanjutnya / Login**.

    ![Form Input Nomor HP](){ width="40%" .center }

    3. Masukkan 6-digit PIN atau Password akun Anda. Jika login pertama kali, masukkan PIN default `123456`.

    ![Input PIN / Password](){ width="40%" .center }

    4. Setelah verifikasi berhasil, Anda akan diarahkan langsung ke **Dashboard Utama JXFleet**.

    ![Dashboard Utama Desktop](){ width="60%" .center }

=== "📱 Mobile App (Android / iOS)"

    ### Langkah-Langkah Login via Aplikasi Mobile:

    1. Buka aplikasi **JXFleet Driver** di ponsel Anda. Masukkan nomor HP yang telah terdaftar pada Tim Pengembang JXFleet (contoh: `628123456789`), lalu tekan tombol **Login**.

    ![Halaman Login Mobile App](){ width="30%" .center }

    2. Masukkan 6-digit PIN akun Anda. Jika ini pertama kali login, gunakan PIN bawaan `123456`.

    ![Verifikasi PIN Mobile App](){ width="30%" .center }

    3. Setelah verifikasi sukses, Anda akan masuk ke halaman utama aplikasi dan siap menerima penugasan.

    ![Halaman Utama Mobile App](){ width="30%" .center }

=== "🌐 Mobile Web"

    ### Langkah-Langkah Login via Mobile Web Browser:

    1. Buka browser di ponsel (Chrome/Safari), lalu akses `web.jxfleet.com`. Pilih menu **Login as Driver**.

    ![Tampilan Awal Mobile Web](){ width="30%" .center }

    2. Masukkan nomor HP yang telah terdaftar pada Tim Pengembang JXFleet (diawali `62`), lalu tekan tombol **Lanjut**.

    ![Form Input Nomor HP Mobile Web](){ width="30%" .center }

    3. Masukkan PIN 6-digit akun Anda.

    ![Input PIN Mobile Web](){ width="30%" .center }

    4. Berhasil masuk ke halaman dashboard Mobile Web.

    ![Dashboard Mobile Web](){ width="30%" .center }

---

> [!TIP]
> Jika Anda mengalami kendala saat masuk akun atau nomor belum terdaftar, silakan hubungi **Tim Pengembang JXFleet (JXFleet Developer Team)** atau manfaatkan panduan [🔑 Lupa Password](002-passwordLupa.md) / [📲 Lupa PIN](003-pinLupa.md).
