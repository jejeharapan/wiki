A. langkah-langkah untuk membuat work order maintenance truck:
1) Memulai Proses: Klik tombol "add maintenance".
2) Mengisi Detail Order: Masukkan nomor polisi kendaraan, nomor SPK, jenis work
order, dan trigger work order.
3) Mengatur Jadwal: Pilih jadwal pengerjaan mulai dan jadwal pengerjaan selesai.
4) Mengisi Info Kendaraan & Lokasi: Masukkan angka odometer (KM), pilih region,
tentukan lokasi maintenance, dan pilih tujuan workshop.
5) Menambahkan Detail Maintenance: Masukkan nama PIC mekanik, isi link foto,
tuliskan deskripsi, dan unggah file maintenance dalam format PDF atau JPG.
6) Submit: Klik tombol "create work order".
7) Validasi Sistem: Sistem akan memverifikasi data melalui dua tahap pengecekan:

Pengecekan Field Wajib: Sistem akan memeriksa apakah ada field wajib yang kosong.
o Jika Ya: Akan muncul pesan error, dan proses berhenti.
o Jika Tidak: Sistem melanjutkan ke pengecekan berikutnya.

• Pengecekan Lampiran: Sistem memeriksa apakah link foto atau file maintenance
sudah diisi.
o Jika Tidak: Akan muncul pesan error untuk mengisi salah satu, dan proses
berhenti.
o Jika Ya: Akan muncul pesan sukses bahwa work order berhasil dibuat, dan
proses selesai.
